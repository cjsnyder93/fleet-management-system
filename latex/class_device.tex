\doxysubsection{Detailed Description}
Base class for \doxylink{class_sensor}{Sensor} and \doxylink{class_actuator}{Actuator}. 

Stores ID, type tag, and active status. No virtual functions allowed (reminder). Members are protected so derived classes can access them directly.
